# Лабораторная работа 1

## Задание

Cоздать форму регистрации как на изображении ниже. Форма должна удовлетворять
следующим требованиям:

- Ширина формы – 400px;
- Внутренний отступ – 8px;
- Цвет кнопки - #0056ff;
- Цвет кнопки при наведении курсора - #417ffb

## Реализация

Разметка в index.html, стили в styles.css, подключены через <link>. Форма
собрана на теге <form> с пятью полями <input> разных типов (text, email, tel,
password) и кнопкой <button>; подсказки внутри полей заданы атрибутом
placeholder. Размеры считаются с box-sizing: border-box, поэтому ширина формы
получается ровно 400px с учётом отступа и рамки. Центрирование на странице и
раскладка полей в столбик реализованы флексбоксом. Цвет кнопки меняется при
наведении через :hover, активное поле подсвечивается через :focus.

## Запуск

Откройте index.html в браузере.
