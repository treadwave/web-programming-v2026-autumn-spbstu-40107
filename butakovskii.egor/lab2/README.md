# Лабораторная работа 2

## Задание

Вариант 24

Реализуйте функцию zipArrays(...arrays), которая объединяет массивы
поэлементно (например, zipArrays([1, 2], ['a', 'b']) → [[1, 'a'], [2, 'b']]).

## Реализация

Функция zipArrays принимает любое количество массивов через rest-оператор и
возвращает новый двумерный массив, группируя элементы по их порядковым индексам.
Она является чистой, выполнится синхронно и не изменяет исходные данные. В
начале алгоритм проверяет, переданы ли аргументы и не являются ли все они
пустыми массивами, в таких случаях сразу возвращая пустой массив. Затем через
Math.max и проверку длин вычисляется размер самого длинного подмассива, который
определяет количество шагов цикла. В цикле for метод map последовательно
собирает элементы с одинаковым индексом изо всех переданных массивов в новые
группы и заносит их в итоговый результат. Решение устойчиво к граничным случаям.
Если переданы массивы разной длины, код ориентируется на самый длинный из них, а
для недостающих элементов коротких массивов запишет undefined, предотвращая
потерю данных. При передаче одного аргумента или, наоборот, большого числа
массивов, синтаксис ...arrays и динамический перебор отработают корректно без
падения в ошибку.
