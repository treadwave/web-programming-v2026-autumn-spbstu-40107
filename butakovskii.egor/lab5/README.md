# Лабораторная работа 5

## Задание

Вариант 24. Задача 5. Создать компонент корзины для покупок Создайте список книг
в магазине. У каждой книге есть кнопка добавить в корзину. Под списком через
горизонтальную линию разместите список товаров, добавленных в корзину.
Функциональность:

- кнопка добавления книги в корзину (добавляет книгу в корзину если ее еще не
  было там или увеличивает счетчик книг в корзине на 1);
- элементы в корзине выводятся по дизайну студента;
- у элемента в корзине можно увеличивать количество шт., удалять этот элемент;
- под корзиной должна выводиться полная сумма товаров из корзины.

## Реализация

Интерфейс собран в одном компоненте App. В каталоге карточки книг рендерятся из
локального массива, отображая название, автора, цену и кнопку добавления.
Разделитель отделяет витрину от корзины. Состояние корзины хранится в хуке
useState в виде массива объектов с полями книги и её количеством. Логика
добавления проверяет наличие товара: если он уже в корзине, счетчик
увеличивается на единицу, если нет — объект пушится со значением quantity: 1.
Внутри корзины реализовано поштучное увеличение количества и полное удаление
позиции фильтрацией по id. Общая сумма вычисляется через reduce как сумма
произведений цен на количество при каждом перерендере. Исходно пустой контейнер
корзины скрыт через display: none для прохождения контракта visible: false. При
клике на добавление блок отображается, рендерит список товаров и обновляет
итоговую стоимость. Все обязательные data-testid проставлены на элементах
согласно сценариям тестов.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
