# Лабораторная работа 1

## Задание

Вариант 24

Задача 1. Создать регистрационную форму (`<form>`) со следующими полями ввода:

- Имя (текстовое поле);
- Фамилия (текстовое поле);
- Email (текстовое поле);
- Пароль (текстовое поле);
- Подтверждение пароля (текстовое поле);
- Дата рождения (поле выбора даты);
- Страна (выпадающий список (`<select>` с `type="text"` для каждого `option`));
- Согласие с условием (checkbox);
- Кнопка отправки. Фон кнопки — зеленый (`#008000`), цвет текста — белый.

В полях ввода необходимо корректно использовать атрибут `type`. Используйте
отступы между полями в `20px`, цвет фона формы — белый, цвет текста — черный.

## Реализация

HTML-структура включает форму с семантическими полями ввода (текст, email,
password, date, checkbox), выпадающим списком `select` с атрибутом `type="text"`
у `option` и кнопкой отправки.

В CSS свойство `box-sizing: border-box` управляет размерами полей, а у `body`
сброшены отступы. Для формы задан белый фон и черный текст. Вертикальные отступы
в `20px` между блоками реализованы через `margin-bottom` у полей ввода. Кнопка
отправки стилизована зеленым фоном `#008000` и белым текстом.

## Запуск

Откройте `index.html` в браузере.
