# Лабораторная работа 3

## Задание

Вариант 24

Реализуйте функцию maxSlidingWindow(arr, k), которая находит максимумы во всех
подмассивах длины k.

## Реализация

Функция maxSlidingWindow(arr, k) возвращает массив максимумов для каждого
скользящего окна длины k, не изменяя исходный массив и работая синхронно.
Алгоритм использует двусвязную очередь для хранения индексов элементов,
обеспечивая линейное время выполнения за один проход по массиву. На каждом шаге
из начала очереди удаляются индексы, вышедшие за левую границу окна, а с конца —
индексы элементов, которые меньше или равны текущему. Текущий индекс добавляется
в конец очереди, благодаря чему в её начале всегда находится индекс
максимального элемента текущего окна, который и записывается в результат, как
только окно полностью сформировано. Граничные случаи обрабатываются корректно:
при пустом массиве или k <= 0 возвращается пустой массив; при k === 1
возвращается копия исходного массива; если размер окна k превышает длину
массива, вычисляется единственный глобальный максимум, который возвращается в
виде массива из одного элемента.
